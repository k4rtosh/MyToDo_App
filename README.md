# MyToDo_App

Личный таск-трекер: проекты → карточки (списки) → задачи с подпунктами.
Один HTML-файл, работает офлайн, синхронизируется через Supabase, ставится на телефон как приложение.

## Быстрый старт

Открой **`index.html`** двойным щелчком — всё работает без сервера и сборки.
Данные хранятся в браузере (localStorage), плюс копия в облаке, если вошёл.

## Что умеет

* Проекты → карточки → задачи с подпунктами; быстрый ввод списком (Enter каждый пункт — задача).
* Дедлайны: поле «срок» (новая задача сразу с сегодняшним днём), бейджи «просрочено / сегодня», фильтры, экран «Сегодня».
* Сортировка: по важности, по сроку, новые сверху и **«Вручную»** — перетаскиванием за ручку `⋮⋮` или `Alt+↑/↓` с озвучиванием для скринридера.
* Массовые операции: «Выбрать» → закрыть, удалить, перенести в другую карточку пачкой.
* Напоминания в браузере о задачах с сегодняшним сроком (колокольчик в сайдбаре).
* Поиск: `F2` — по всем задачам (ведёт к задаче и подсвечивает её), `Shift+F2` — по текущей карточке.
* Облако Supabase: вход, синхронизация между устройствами, офлайн-first. В окне «Облако» видно, сколько строк ждёт отправки, и есть кнопка «Забрать из облака» на случай расхождения устройств.
* Экспорт: карточка в `.txt` (тот же формат, что понимает импорт), `.csv` для Excel (BOM + «;»), вся база в `.json`.
* Импорт текста с дедупликацией: повторная вставка того же списка не плодит копии.
* История изменений (последние 300 событий) и напоминание о резервной копии раз в неделю.
* Фильтры карточки: статус, быстрые («Просрочено / Сегодня / 7 дней / Срочные» — повторный клик снимает), теги в сворачиваемом облаке с отдельной кнопкой «Сбросить».
* Мобильная вёрстка: шапка в одну строку (бургер, «назад» + название, компактные действия), подпункты на всю ширину карточки, длинные подписи обрезаются многоточием.

## Структура

```
index.html            — всё приложение (HTML + CSS + JS в одном файле)
manifest.webmanifest  — PWA: имя, иконки, запуск без адресной строки
sw.js                 — service worker: офлайн-кэш оболочки
favicon.ico           — иконка вкладки, 16/32/48
icons/                — PWA-иконки 192/512, apple-touch-icon, favicon.svg и 16/32 px
supabase/schema.sql   — таблицы, индексы, триггеры, RLS для Supabase
supabase/002-position.sql — миграция: поле position для ручной сортировки
docs/ARCHITECTURE.md  — архитектура, слои, роадмап, что оптимизировать
docs/MIGRATION-SUPABASE.md — план перехода на облако и Pages
tools/make-icons.py   — все иконки сразу: PWA 192/512, apple-touch-icon, favicon (svg/16/32/ico)
```

Личные выгрузки задач (`data/`, `*.private.json`) в репозиторий не коммитятся — они в `.gitignore`.

## Облако (Supabase)

* Проект: `https://ojxvxvqdesgjrdunhbkq.supabase.co`
* В `index.html` встроен **publishable key** — он публичный по назначению, защита данных в RLS.
* **secret key в код не попадает никогда** (он обходит RLS, только для сервера).
* Схема БД: `supabase/schema.sql` → выполнить в SQL Editor (идемпотентно, можно повторять).
* Вход в приложении: чип `☁` в шапке → «Зарегистрироваться» или «Войти».

Как это работает:

1. При входе локальные данные **сливаются** с облачными (по `updated_at`, побеждает более свежая версия).
2. Дальше каждое изменение уходит в облако (diff по изменённым записям, не весь массив).
3. Удаление — мягкое (`deleted_at`), чтобы не «воскресало» на втором устройстве.
4. Без сети всё работает локально, изменения уходят при появлении связи.
5. Синхронизация: после правок (1.5 с), при возврате на вкладку, при появлении сети, раз в минуту.

## Публикация на GitHub Pages

```bash
git init -b main
git add -A
git commit -m "To Do: приложение с облаком и PWA"
git remote add origin https://github.com/k4rtosh/MyToDo_App.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
Сайт: `https://k4rtosh.github.io/MyToDo_App/`.

> Если репозиторий создан с README, push отклонится. Тогда: `git pull --rebase origin main` и снова `git push`.

Установка на телефон: Android Chrome → «Установить приложение»; iOS Safari → «Поделиться → На экран Домой».

## Данные

* Экспорт/импорт: кнопки `⤓` и `⤒` в подвале сайдбара (импорт **заменяет** данные целиком).
* Экспорт не включает удалённые записи.
* Перед крупными изменениями делай экспорт — это страховка.

## Разработка

* Правится один файл — `index.html`. Сборка не нужна.
* Иконки: `python tools/make-icons.py` (нужен Pillow).
* Генератор выгрузки этапов: `node tools/make-dev-json.js` (читает экспорт приложения, пишет в `data/`).
* Проверять локально: открыть `index.html`, консоль браузера (F12).

## Ограничения

* Штрихкоды/QR — не про это приложение, это тренажёр ZPL (`zpl-trainer.html` вне репозитория).
